# Images de la présentation

Ajoute ici les visuels en conservant exactement les noms utilisés par les placeholders :

- `cover-medlink.webp`
- `patient-dashboard.png`
- `doctor-dashboard.png`
- `admin-dashboard.png`
- `architecture.png`

Les images d'enquête peuvent être rangées dans `survey/`, celles de comparaison concurrentielle dans `competition/`.

Formats recommandés : WebP ou PNG. Captures d'interface : largeur 1400 px ou plus, texte lisible, sans données médicales personnelles réelles. Utiliser des données fictives/anonymisées pour toute capture destinée à une présentation publique.
